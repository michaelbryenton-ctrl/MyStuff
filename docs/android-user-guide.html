XRoar user guide

Setup, everyday controls, and the new CoCo position-hold gamepad method.

XRoar emulates Dragon, Tandy Color Computer (CoCo), and Tandy MC-10 computers. This Android edition uses native emulation and does not include machine ROMs or game media.

Updating an existing installation: Install xroar-1.0.7-debug.apk over the existing app. Do not uninstall first: uninstalling or clearing app storage deletes imported ROMs and media. Keep your original files outside the app as backups.

1. Install and select a computer

  1. Open the APK on your Android device. If Android requests it, allow installation from the app you used to open the file; you can disable that permission afterward.
  2. Open XRoar. In Computer to emulate, choose the machine matching your firmware and software.
  3. Tap Import ROM files and select firmware you are entitled to use. Extract firmware ZIPs first; import the ROM files themselves.

Available choices are CoCo NTSC/PAL, CoCo 3 NTSC/PAL, Dragon 32, Dragon 64, and MC-10. Android 5.0 or later is required.

2. Supply the correct firmware

For a standard CoCo, normally import Color BASIC (bas12.rom, or supported bas10–bas13) and Extended Color BASIC (extbas11.rom or extbas10.rom). A supported 16 KB combined image named coco.rom can supply both halves.

extbas11.rom alone is usually not the complete firmware. A .ccc game is a cartridge, not machine firmware. Other machines need their own ROMs; follow the launcher's missing-firmware message and suggested filename. Preserve recognized filenames rather than renaming firmware arbitrarily.

3. Choose software and start

Tap Choose cartridge, tape, disk, or program, select your software, and then tap Start XRoar. Imported files are copied to the app's private storage. A selected .ccc cartridge is launched with autorun enabled.

Everyday use

Display, keyboard, and media

The emulator picture sits in the top half of the window. Controls occupy separate rows below it, not over the picture. CoCo machines have a receiver-style bezel around the live display; Dragon and MC-10 use a plain frame.

ControlWhat it does

Hide the phone keyboard with Android's keyboard-dismiss control or Back when you no longer need it. Phone-keyboard taps use a short emulated hold and gap so software can detect them; physical keyboards retain normal held-key behavior.

Cassettes and ZIP archives

  • Select cassette files through the media picker, not Import ROM files.
  • A ZIP containing one CAS and a same-named WAV is extracted and the CAS is selected.
  • If an archive contains several different programs, extract it yourself and select the intended file.
  • If an older imported ZIP prompts you to select it again, choose it again through the media picker so the tape can be extracted.

At startup, tape autorun examines the tape header. Machine-code tapes use CLOADM and, where appropriate, EXEC; BASIC tapes use CLOAD and RUN. Normally you do not need to type those loading commands yourself for a selected supported cassette. Some programs still require their own title-screen input.

Storage and session limits

Imports preserve the source files' names and leave the originals outside the app untouched. Returning to the library or exiting preserves imported files, but does not promise to save current emulated RAM, progress, or changes made by a running program. Keep separate backups of valuable files.

Input reference

Touch and Direct gamepad controls

Touch: the default input source

  1. Leave the selector on Input: Touch.
  2. Touch or drag on the emulator display or lower pad to select an absolute analog position.
  3. Lift your finger: the selected position stays where you left it.
  4. Double-tap to fire. Hold the second tap for continuous fire; lift to release.

A quick fire tap produces a minimum 120-millisecond pulse so the emulated CPU can observe it. This remains the original non-centering touch behavior; the new gamepad mode does not replace it.

Connect a gamepad

  1. Connect an Android-recognized controller. For USB, use a suitable USB host/OTG connection supported by your phone.
  2. In the emulator, tap Input: Touch to switch to Input: Gamepad.
  3. Check the controller name and live position/fire indication in the lower pad. “Connect a controller” means no supported controller is currently selected.
  4. Choose Port: Right or Port: Left as required by the game.

The app uses the first available controller. Touch movement is disabled while Gamepad input is selected. Keyboard, Enter, and Space remain available. Switching back to Touch restores its independently stored touch position.

Direct mode: unchanged original mapping

The first gamepad mode is Gamepad: Direct. Left-stick displacement maps directly to the full emulated analog range. If your physical stick springs back to its centre, the emulated position centres too.

  • D-pad: selects directional extremes and overrides the stick while used. Opposing directions cancel.
  • A: fires. Holding A keeps fire pressed; quick taps retain the minimum pulse.
  • D-pad centre: also fires on controllers that report that button.
  • B: has no recenter action in Direct mode.
Controller recognition and button layouts depend on Android and the controller. This version has no raw-USB driver or custom button-remapping screen.

New in 1.0.7

CoCo position-hold gamepad method

A spring-centred gamepad cannot physically behave like a non-centering CoCo joystick. This mode keeps a separate analog position in software: the stick controls how quickly that position changes, not the absolute position itself.

Enable and use it

  1. Select Input: Gamepad.
  2. Tap Gamepad: Direct. The button changes to Gamepad: CoCo position-hold. The mode selector appears only in Gamepad input.
  3. Deflect the left stick toward the desired position. A small deflection adjusts slowly; a larger deflection adjusts faster.
  4. Release the stick to hold the current emulated position. Use the D-pad for slower, fine adjustments.
  5. Press A to fire. Press B to centre both axes. Holding B keeps them centred, even if the stick is deflected.

For example, push right briefly, release to keep that position, then tap left on the D-pad to make a small correction. Holding a direction continues adjusting even without new controller events. Press B when you want to return to neutral. Tap the mode button again to return to Direct.

What “hold” means

This is cursor-like relative positioning, not an exact absolute replica of a physical CoCo stick. The game interprets the held analog value: it may continue moving an object, maintain an aiming position, or behave differently. Releasing the controller does not necessarily stop motion inside the game.

Safety resets override holding. Disconnection, app pause, focus loss, changing the input source or port, and changing gamepad mode centre the gamepad and release fire. The mode remains selected within the session, but stored position is not preserved through those resets. A new emulator session starts with Touch input and Direct gamepad mode.

Reference and troubleshooting

How it works and what to check

Implementation details

  • Each axis uses a range of 0–65,535; neutral is 32,768. Fractional position is retained internally and rounded for output.
  • Stick input is normalized with a dead zone of at least 15%, enlarged when the controller reports a larger dead zone. Speed is proportional to the normalized deflection outside it.
  • At full normalized deflection, stick speed is one full axis range per second. From neutral to an edge takes roughly half a second. D-pad speed is 8,192 units per second—about one eighth of full-stick speed.
  • The update loop requests an approximately 16-millisecond interval and integrates actual elapsed time. A delayed frame is capped at 100 milliseconds to avoid a large jump after a UI stall.
  • Position is clamped at the endpoints. D-pad input takes priority over the stick; both key-based and hat-axis D-pads are supported. Holding B suppresses adjustment until B is released.
  • A retains the existing minimum 120-millisecond fire pulse. The loop stops when adjustment is unnecessary; lifecycle resets cancel movement updates.
